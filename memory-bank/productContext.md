# 제품 컨텍스트

## 문제 해결
- 복잡한 텍스트 편집 기능이 필요한 웹 애플리케이션
- 반응형 디자인이 필요한 모바일/데스크톱 환경
- 데이터베이스 연동이 필요한 콘텐츠 관리

## 사용자 경험 목표
1. 직관적인 인터페이스
   - 쉽게 이해할 수 있는 에디터 도구
   - 명확한 기능 구분
   - 직관적인 아이콘 사용

2. 반응형 디자인
   - 모바일 환경 최적화
   - 태블릿/데스크톱 지원
   - 다양한 화면 크기 대응

3. 성능 최적화
   - 빠른 로딩 시간
   - 부드러운 편집 경험
   - 효율적인 데이터 처리

## 작동 방식
1. 텍스트 에디터
   - Quill Editor 기반 구현
   - 다양한 서식 옵션 제공
   - 미디어 파일 지원

2. 데이터 관리
   - Prisma를 통한 데이터베이스 연동
   - 효율적인 데이터 저장/조회
   - 안정적인 데이터 백업

3. UI/UX
   - Tailwind CSS를 활용한 디자인
   - 일관된 디자인 시스템
   - 접근성 고려

### 액터 설명
*   **사용자 (User)**: 웹사이트의 일반 방문자 및 회원으로, 콘텐츠를 조회하고 상호작용하며 특정 기능을 이용합니다.
*   **관리자 (Admin)**: 웹사이트의 콘텐츠 및 전반적인 설정을 관리하는 특수 권한을 가진 사용자입니다.

### 유스케이스 설명
#### 일반 사용자 기능
*   **웹사이트 탐색**: 사용자가 다양한 페이지와 콘텐츠를 둘러봅니다.
*   **게시물 조회**: 블로그, 게시판, 유머, Q&A, 위키 등의 게시물 콘텐츠를 읽습니다.
*   **갤러리 조회**: 이미지 갤러리 및 유튜브 갤러리 콘텐츠를 봅니다.
*   **문의 메시지 전송**: 웹사이트 관리자에게 문의 메시지를 보냅니다.
*   **방명록 사용**: 방명록에 글을 작성하거나 기존 글을 조회합니다.
*   **사이트 검색**: 웹사이트 내의 특정 콘텐츠나 정보를 검색합니다.
*   **외국어 학습**: 영어 또는 일본어 학습 기능을 이용합니다.
    *   **텍스트 파일 업로드**: 학습할 문장이 담긴 텍스트 파일을 업로드합니다.
    *   **문장 음성 재생**: 업로드된 문장 또는 선택된 문장을 음성으로 듣습니다.
    *   **재생 제어**: 음성 재생을 일시정지, 재개, 정지합니다.
    *   **재생 설정 변경**: 음성 재생 속도나 문장 간 간격을 조절합니다.

#### 관리자 기능
*   **관리자 기능 접근**: 관리자 페이지에 로그인하여 접근합니다.
*   **콘텐츠 관리**: 게시물, 이미지, 비디오 등 웹사이트의 다양한 콘텐츠를 생성, 수정, 삭제합니다.
*   **사용자 계정 관리**: 사용자 정보를 조회, 수정, 삭제하고, 계정 활성/비활성화 등의 작업을 수행합니다.
*   **메뉴 및 사이트 설정 변경**: 웹사이트의 내비게이션 메뉴 구조, 테마, 배경 색상 등 전반적인 사이트 설정을 변경합니다.
*   **데이터베이스 작업 수행**: 필요한 경우 데이터베이스 모델에 대한 직접적인 CRUD 작업을 수행합니다.
