# 현재 작업 컨텍스트

## 현재 작업 초점
- Quill 에디터 기능 개선 완료 및 시스템 안정화.

## 최근 변경 사항
1.  **Quill 에디터 기능 고도화**
    - **다중 이미지 업로드 및 Base64 임베딩**: 사용자가 여러 이미지를 선택하면, 파일들을 Base64 문자열로 변환하여 에디터 콘텐츠에 직접 삽입하는 기능을 구현했습니다. 이로써 별도의 서버 사이드 업로드 로직 없이 이미지를 콘텐츠의 일부로 관리할 수 있게 되었습니다.
    - **이미지 편집 기능 추가**: `quill-resize-module` 라이브러리를 도입하여, 에디터 내에서 사용자가 직접 이미지 크기를 조절하고, 이미지를 삭제하거나 다른 이미지로 교체할 수 있는 기능을 추가했습니다.
    - **SSR 호환성 확보**: 클라이언트 사이드에서만 동작하는 라이브러리로 인해 발생하던 서버 사이드 렌더링(SSR) 오류를 `onMounted` 훅과 동적 `import()`를 사용하여 해결했습니다.

2.  **관리자 페이지 기능 구현 완료**
    - **DB 관리**: Prisma 스키마를 동적으로 분석하여 모든 DB 모델에 대한 CRUD UI를 제공하는 기능을 구현했습니다.
    - **사용자 관리**: 사용자 목록 조회(페이지네이션, 검색, 정렬 포함), 생성, 수정, 삭제, 비밀번호 재설정 등 전체 관리 시스템을 구현했습니다.
    - **동적 메뉴 관리**: 데이터베이스 기반으로 메뉴를 생성하고, 드래그앤드롭으로 순서를 변경하는 등 동적 메뉴 시스템을 완성했습니다.

3.  **핵심 시스템 안정화**
    - **인증 시스템**: `useAuth` composable을 리팩터링하여 전역 인증 상태 관리 로직을 안정화하고 관련 버그를 해결했습니다.
    - **UI/UX 개선**: 전역 레이아웃, 라우팅, 공용 컴포넌트(모달, 토스트 등) 관련 이슈를 해결하여 사용자 경험의 일관성을 확보했습니다.

## 최근 변경 사항 (YYYY-MM-DD)

- **인증 시스템 리팩터링 및 디버깅**
  - **문제**: 관리자로 로그인해도 헤더가 업데이트되지 않고, 관리자 페이지 접근 시 메인으로 튕기는 현상 발생.
  - **원인 분석**:
    1.  `useAuth` composable이 반환하는 상태 객체 구조가 비직관적이어서(`auth.auth.value.user`), 컴포넌트에서 상태 접근 시 실수가 발생함.
    2.  `useAuth` 리팩터링 과정에서 `isAdmin` 속성이 누락되어, `AppMenu`가 관리자 메뉴를 렌더링하지 못함.
    3.  관리자 전용 페이지들(`admingallery`, `adminboard`)이 리팩터링 이전의 방식으로 권한을 확인하고 있어 접근이 차단됨.
  - **해결**:
    1.  `useAuth`를 리팩터링하여 `isLoggedIn`, `user`, `isAdmin`을 computed 속성으로 직접 반환하도록 구조를 개선함.
    2.  `Nav.vue`, `GalleryList.vue`, `admingallery`, `adminboard` 등 `useAuth`를 사용하는 모든 컴포넌트와 페이지를 새로운 구조에 맞게 수정함.
    3.  리팩터링 중 발생한 `computed` 함수의 잘못된 import 경로를 수정함.

- **Nuxt/Vue 경고 메시지 해결**
  - `useFetch` 경고: `BlogIndex.vue`에서 `onMounted` 내부에 `useFetch`를 사용하던 구조를 Nuxt 권장 방식인 `<script setup>` 최상단에서 호출하는 방식으로 변경함.
  - `showMobileCategory` 경고: `blog.vue` 레이아웃에 `showMobileCategory` ref가 선언되지 않아 발생한 문제를 해결함.
  - Vue Router `to="#"` 경고: `AppMenu.vue`에서 경로가 없는 메뉴 항목에 대해 `<NuxtLink>`를 생성하지 않도록 `v-if` 조건을 추가하여 해결함.
