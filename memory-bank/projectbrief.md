# 프로젝트 개요

## 프로젝트 목적
- Nuxt.js를 사용한 웹 애플리케이션 개발
- 텍스트 에디터 기능 구현 (Quill Editor 활용)
- 반응형 웹 디자인 적용

## 핵심 요구사항
1. 텍스트 에디터 기능
   - 리치 텍스트 편집 기능
   - 이미지, 비디오 삽입 지원
   - 반응형 디자인 적용

2. 기술 스택
   - Nuxt.js
   - Vue.js
   - Prisma (데이터베이스 ORM)
   - Tailwind CSS

## 프로젝트 범위
- 텍스트 에디터 컴포넌트 구현
- 데이터베이스 연동
- 반응형 UI/UX 구현

## 목표
- 사용자 친화적인 텍스트 에디터 구현
- 안정적인 데이터 저장 및 관리
- 최적화된 성능 제공
